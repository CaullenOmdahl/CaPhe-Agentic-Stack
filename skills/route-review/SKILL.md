# Route review

Read private telemetry, corpus metadata, policy, overlay, and the public registry. Never edit any of them.
Use only these recommendations: `promote`, `demote`, `replace`, `retire`, `reprobe`, `refresh-rates`, and
`collect-more`. A report is not promotion evidence: promotion requires owner-approved tolerances and paired
accepted-task evidence including parent and repair costs.
